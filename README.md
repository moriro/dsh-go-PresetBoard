# dsh-PresetBoard

给 **dsh-go 手机 App 原生界面**用的预设板：把常用提示词、skill 说法、人设收进一个「预设」按钮。

- 输入框上方只有一个「预设」胶囊。
- 面板顶部「浏览 / 编辑」切换。
- 浏览：按分组排列，点一条插入输入框，**不会自动发送**；输入框里已有文字时自动换行。
- 编辑：改名称、备注、#标签、分组、内容、置顶；排序、删除、新建预设 / 分组。
- 分享：单条预设可复制成一段分享码；「粘贴添加」把分享码加回预设板。
- 导入 / 导出：导出写 `手机存储/Download/DSH-Go/preset-board-时间.json` 并复制路径；导入走系统选文件。
- 内容最多 2000 字（dsh-go 原生输入框和插入效果的上限）。到 2000 字时显示红色 `😫2000`。

## 安装

```sh
dsh plugin --profile web add dsh-presetboard
```

从 DSH Go 插件市场安装时不用敲命令。

## 数据

预设保存在：

```
$DSH_HOME/dsh-go/plugin-data/preset-board/data.json
```

升级或卸载插件不会删这份数据。

## 隐私

- 不联网。
- 只在点「预设」胶囊时读一次输入框文字，用来判断插入前要不要换行。
- 导入时只通过系统文件选择器读取你选中的 JSON。
